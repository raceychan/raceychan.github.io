# Feature: Add a "Wiki" section and navbar item

## Plan

### Technical Analysis
- Current site: Docusaurus 3.x with `classic` preset, local search plugin `@easyops-cn/docusaurus-search-local`, i18n (`en`, `zh`, `ja`, `ru`). See `docusaurus.config.ts: plugins`, `presets`, and `themeConfig.navbar`.
- Existing "How do I …?" content lives under `docs/how_do_i` with a `_category_.yml` and many MD files. It currently renders under the main Docs (`/docs/how-do-i`).
- Goal: Introduce a first-class "Wiki" section (like "Tutorial" and "Blog") at `/wiki`, add a top navbar item, and migrate/organize all "how-do-i" content into a tree of categories for fast discovery.

### Proposed Solution
1) Add a second Docs instance (multi-instance docs) using `@docusaurus/plugin-content-docs` with `id: 'wiki'`:
   - `path: 'wiki'` (new folder)
   - `routeBasePath: 'wiki'` (renders at `/wiki`)
   - `sidebarPath: './sidebars.wiki.ts'` with an autogenerated sidebar
2) Add a navbar item of type `docSidebar` for the new plugin instance:
   - `docsPluginId: 'wiki'`, `sidebarId: 'wikiSidebar'`, `label: 'Wiki'`, `position: 'left'`
3) Migrate `docs/how_do_i/**` → `wiki/how-do-i/**`, organized by categories with `_category_.json` files and an `index.md` landing page.
4) Keep search working: local search plugin indexes all docs instances by default; no extra config should be needed.
5) Optional redirects to avoid link rot:
   - Add `@docusaurus/plugin-client-redirects` or per-doc `slug` metadata to map `/docs/how-do-i/*` → `/wiki/*`.
6) i18n: keep initial rollout in English; optionally later mirror `wiki` in `i18n/<locale>/docusaurus-plugin-content-docs-wiki`.

Docs references:
- Multiple docs instances: https://docusaurus.io/docs/docs-multi-instance
- Sidebar autogenerated: https://docusaurus.io/docs/sidebar/autogenerated
- Navbar docs item: https://docusaurus.io/docs/api/themes/configuration#navbar-items
- Client redirects: https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-client-redirects
- Category metadata: https://docusaurus.io/docs/sidebar/items#category-metadata

2) Create `sidebars.wiki.ts` (autogenerated):
   ```ts
   // sidebars.wiki.ts
   import type { SidebarsConfig } from '@docusaurus/plugin-content-docs';

   const sidebars: SidebarsConfig = {
     wikiSidebar: [{ type: 'autogenerated', dirName: '.' }],
   };

   export default sidebars;
   ```

3) Create initial structure under `wiki/` and migrate content:
   - `wiki/index.md` (landing page for Wiki)
   - `wiki/how-do-i/_category_.json` (e.g., label: "How do I …?", collapsed: true)
   - Copy all MD/MDX from `docs/how_do_i/` into `wiki/how-do-i/`, optionally splitting into topical subfolders:
     - `wiki/how-do-i/routing/*`
     - `wiki/how-do-i/requests/*`
     - `wiki/how-do-i/responses/*`
     - `wiki/how-do-i/auth/*`
     - `wiki/how-do-i/websockets/*`
     - `wiki/how-do-i/testing/*`
     - `wiki/how-do-i/deployment/*`
     - `wiki/how-do-i/observability/*`
     - `wiki/how-do-i/ops/*` (e.g., migrations, rate limiting)
   - Add `_category_.json` files per folder to control labels and order. Example:
     ```json
     { "label": "Routing", "position": 1, "collapsed": true }
     ```

4) Wiki landing page content (example `wiki/index.md`):
   ```md
   ---
   id: index
   title: Lihil Wiki
   slug: /
   ---

   Welcome to the Lihil Wiki. Browse practical, task-oriented guides and FAQs.
   ```

5) Optional: keep old `docs/how_do_i/index.md` but convert it into a short stub with links pointing to `/wiki/how-do-i` to preserve navigation within the Docs tutorial section.

6) Build and validate:
   - Start dev server and verify `/wiki` renders and the "Wiki" navbar item appears.
   - Confirm search returns wiki results.
   - Confirm redirects (if configured) from `/docs/how-do-i/*` to `/wiki/*`.

### Success Criteria
- New top-level navbar item "Wiki" is visible and routes to `/wiki`.
- `/wiki` loads an autogenerated sidebar "wikiSidebar" with clear category groupings.
- All former `docs/how_do_i/**` articles are accessible under `/wiki/how-do-i/**` without broken links.
- Local search returns results from the Wiki.
- Existing locales keep working; English is the default for the Wiki.
- Optional: old `/docs/how-do-i/*` URLs redirect to `/wiki/*`.
